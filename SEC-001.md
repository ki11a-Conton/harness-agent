# TASK: SEC-001

## Goal

Implement the security surface in `packages/security`: deterministic permission engine (SEC-001), approval store/resolver (SEC-002), sandbox manager with symlink-escape detection (EXEC-001 / §19–§20).

## Dependencies

CONTRACT-001.

## Scope

### Create

- `packages/security/package.json`, `tsconfig.json` (deps: @ar/contracts)
- `packages/security/src/glob.ts` — normalizePath + glob matching for Windows paths
- `packages/security/src/permission.ts` — DeterministicPermissionEngine (precedence global→project→agent→session→tool→call; most-specific rule wins; equal specificity → deny; no match → defaultEffect, default "ask") + defaultEffectForRisk (readonly→allow, side_effect/elevated→ask, critical→deny)
- `packages/security/src/sandbox.ts` — SandboxManager: filesystem modes (read-only/workspace-write/full), realpath-based escape detection incl. UNC paths, network policy, command allowlist
- `packages/security/src/approval.ts` — InMemoryApprovalStore (settle idempotent, expire/cancel paths) + StoreApprovalResolver

## Acceptance Criteria

- Engine: rule precedence, conflict-deny, fallback defaultEffect, risk defaults
- Sandbox: outside-workspace write denied, symlink escape denied, UNC denied, read-only blocks writes, allowlist gates commands, network deny/allowlist
- Approval: allow/deny/expire/cancel resolve exactly once; late settle returns existing decision
