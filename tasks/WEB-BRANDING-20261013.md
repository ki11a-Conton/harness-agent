# Harness Agent Web 品牌统一

## 做什么

所有产品界面采用 Harness Agent 名称和独立 H 图标，移除上游产品名称、鲸鱼、字标及欢迎插画。覆盖首次启动、空会话、侧栏、浏览器标题、PWA、设置、插件说明、文档预览错误、桌面/移动端及旧客户端。

## 怎么做

保持原始 MIT/第三方许可证、npm 发布物、源码来源记录不变；从固定原件确定性生成明确标记的本地品牌衍生组件，原件与衍生件分别校验。三个品牌 slot 使用真实 React 组件；产品文案在组件资源中替换，不扫聊天内容、不注入遮挡 DOM、不禁用控件。内部模块 ID、实际模型供应商 ID 保持真实。限定 Web 层，保留现有 Core 与权限边界。新增品牌资源仍经过静态路径/版本校验。

## 怎么验收

- 原始发布物离线校验、衍生件独立重算及篡改拒绝通过。
- typecheck、Web unit/integration/security 和静态路径回归通过。
- 生产 Web + Chromium 三视口、中英文首次欢迎/空会话/侧栏/深浅主题/设置/插件页，检查可见文字、可访问名称、图标 SVG、标题和 PWA。保留截图、HTTP 与原始结果，不使用响应 mock。
- 固定 clean 源码独立安装包复验普通 coding 流程及品牌；记录实际通过/失败范围，执行文档门后 commit、native git 推送 main。
