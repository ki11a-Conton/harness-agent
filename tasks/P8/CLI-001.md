# TASK: CLI-001

## Goal

Create the `apps/cli` package (`@ar/cli`) per AGENT_ARCHITECTURE_PLAN v2.0 §86 (CLI), §87 (Doctor Command), §88 (Development Protocol), §173 (Completion Contract), §174 (Final Response Contract).

## Why

The runtime needs a host-facing command surface (`agent run/resume/cancel/approve/...`) that drives the runtime through the public RPC face only (§161) — no reach-through into Core, tool execution, permission logic, or session persistence. The CLI is a client, exactly like the Desktop (§85).

## Dependencies

- RPC-001 (`packages/gateway`: createRuntimeRpc, RpcMethodRegistry, InMemoryTransport)
- CORE-001 (`packages/core`: AgentRuntime)
- `@ar/session` (SessionService), `@ar/security` (InMemoryApprovalStore), `@ar/observability` (exportEpisode), `@ar/tools` (ToolRegistry / ToolOrchestrator)

## Preconditions

`pnpm-workspace.yaml` already includes `apps/*`. Root tsconfig references all packages.

## Scope

### Create

- `apps/cli/package.json` — name `@ar/cli`, ESM, `bin: { "agent": "./src/main.ts" }`, deps on @ar/contracts/core/session/gateway/security/observability/tools (workspace:*), devDep @ar/model (test fakes). No third-party dependencies.
- `apps/cli/tsconfig.json` — extends `../../tsconfig.base.json` (apps/ is outside packages/), references the 7 runtime deps.
- `apps/cli/src/main.ts` — entry: hand-written `agent <command> [args]` parsing (no argv library), wires default in-memory deps, calls runCommand, prints lines, returns exit code. Main-guard so the file is importable.
- `apps/cli/src/commands.ts` — `runCommand(argv, deps): Promise<{ exitCode, lines }>`; commands: run/resume/cancel/approve/agents/tools/skills/sessions/trace/doctor; unknown command and missing args → exitCode 1 + usage.
- `apps/cli/src/doctor.ts` — `runChecks(deps): Promise<CheckResult[]>` (independent of command parsing).
- `apps/cli/src/index.ts` — public exports.
- `apps/cli/src/cli.test.ts` — 10+ cases; no real process spawn; in-memory stores + ScriptedModelProvider.
- `tasks/P8/CLI-001.md` (this file)

### Modify

- `tsconfig.json` (root references: add `./apps/cli`)

### Forbidden

- No third-party argv/dependency packages
- No spawn of the real CLI process in tests
- No reach-through to runtime internals outside the RPC surface in commands (listing/session-browsing read the store directly where no RPC method exists)
- No changes to packages/* code

## Contracts

CLI only calls `session.*`, `agent.list`, `tool.list`, `skill.list`, `trace.get` over RPC (§84/§161). `sessions` reads the SessionStore directly (no `session.list` RPC method exists); `trace` uses observability `exportEpisode` (§77).

`run` prints the §173 structured outcome: status / summary / files changed / tests / verification / remaining issues, derived from the turn outcome + event stream + message store — never from free-form model memory.

## Security Invariants

- Errors over RPC surface only `{ code, message }`; the CLI renders those (never stacks).
- `agent run` picks the agent via `agent.list` (safe projection, no systemPrompt — §161).
- Approval decisions go through `session.approve` (one-shot, store-backed).

## Tests

- run success / run failure exit codes + §173 lines
- resume (known + unknown session), cancel (running + not_running)
- approve allow / deny / unknown / invalid value
- agents / tools / skills / sessions listing output
- trace exports an episode package to a temp dir (files present)
- doctor OK on healthy deps; ERROR (exit 1) with a throwing store
- unknown command → exit 1 + usage; missing args → exit 1 + usage
