1. The defect (reproduced as a test, not asserted statically)
------------------------------------------------------------

`try { await runTurn() } finally { await poller.stop() }` with BOTH failing:

  await expect(attempt()).rejects.toThrow("cleanup-error");       -> PASSES
  await expect(attempt()).rejects.not.toThrow("turn-error");     -> PASSES

i.e. the thrown error is ONLY "cleanup-error". The original "turn-error" is
destroyed, because JavaScript replaces an in-flight exception with one raised
from `finally`. R76's own tests asserted only the cleanup-succeeds path, so this
cell was never exercised. Test name in the suite:

  E4-R80 (F80-1): turn error and cleanup error precedence
    > REPRO: the R76 `finally { await stop() }` shape LOSES the original turn error
