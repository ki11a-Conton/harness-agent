## 问题与实现

[原始干净基线](agent-next5-20261005/raw/baseline-result.json) 在实际JSONL/SQLite上各检索256条互不重叠token记忆，返回5项、无抑制，但各做32640次token membership检查。无交集或空集的Jaccard为0，不可能达到既有0.6阈值；仍逐一遍历全部保留项，基础设施工作预算失败，与模型策略无关，符合AGENTS.md Runtime Freeze第4项维护例外。基线记录SHA/clean和原始计数；没有伪造当时未记录的dist指纹。[基线Git源码](agent-next5-20261005/raw/baseline-source/retrieval.ts)是之后从原commit提取的原字节，不称为测量当时的现场快照。

本次检索内维护token→保留项的倒排列表；收集至少共享一个token的候选，去重并按保留索引升序，再调用原tokenSimilarity及0.6阈值。只索引保留项，不索引被抑制项；保留TopK以外的幸存者用于后续冲突报告；空token项按原行为保留。无跨调用缓存，修改或删除记忆后重新检索。评分、过滤、排序和最终返回阶段保留原字节。
