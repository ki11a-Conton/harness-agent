## 实际限制

- 已知 read_file 真实 FIFO 读超时后仍占锁/后台读取的缺陷 **UNFIXED、OUT_OF_SCOPE**，[原始生产证据](agent-next2-20261005/raw/audit-tools/baseline-fifo/result.json) 保留；R3 仅修搜索路径。
- JSONL 采用原有进程内协作锁，跨进程一致性 **NOT_GUARANTEED**。SQLite 反馈只更新 usefulness，不迁移 schema。
- 没有原子反馈能力的外部自定义 store **跳过持久反馈**，输出一次固定、不含原始异常/私有内容的 degraded 诊断，仍保留检索、正常 turn 和进程 ROI；不回退到不安全 get→整行 update。
- paid provider calls=0；真实模型任务质量、champion promotion、Windows native runtime **NOT_RUN**。loopback HTTP 和 scripted Harness 证明工程合同，不能推断真实模型任务成功率。
