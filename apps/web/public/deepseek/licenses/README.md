# DeepSeek frontend redistributed notices

The official npm payloads are MIT, while bundled fonts, third-party software,
and individual brand artwork retain their own terms. Published-package registry
metadata, manifests, license originals and integrity checks are preserved here.

- `published-packages.json`: 67 npm tarballs; no gitHead is available.
- `frontend-asset-hashes.json`: 126 byte-identical npm frontend assets.
- `fonts/`: Montserrat OFL, KaTeX font OFL, KaTeX software MIT and font metadata.
- `icons/`: individual icon attribution evidence, artwork, terms and known gaps.
- `bundled-notices/`: original embedded PDF/spreadsheet notices and license comments.
- `upstream-source-reference/`: pinned source inspection inputs; not the npm build lock.
- `shell-reference/`: isolated rebuild inputs and notices; not the published build closure.

Remaining evidence gaps are recorded in the icon inventory and the repository
report `docs/web-deepseek-frontend-licenses.md`. Neither upstream direct-dependency
notices nor these reference locks establish the complete original npm build
closure or the missing individual icon terms.
