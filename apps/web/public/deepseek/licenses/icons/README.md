# Redistributed brand icon sources and terms

The icon paths below are present in the official npm frontend assets and match
Simple Icons 16.31.0 exactly. Simple Icons package code/data is CC0-1.0, but its
DISCLAIMER.md says that this does not make every brand icon CC0. Individual
metadata and its source URL are preserved in icon-inventory.json.

Upstream SiteGlyph uses currentColor in place of the brand fill. Upstream
CodeFileIcon adds a colored background and scaling transform around an unchanged
brand path and may use a different fill. The matching standalone SVGs are
retained under svg/. No additional changes have been made to the published
official frontend geometry by this migration.

Individual creator/copyright fields are absent from the npm metadata. The
brand/project title and source URL are recorded as the attribution evidence
available here; absent individual terms or authors are an open evidence gap.
