The product uses its own H mark, wordmark, PWA name and onboarding illustration.
Ten browser entry modules have explicitly marked local derivatives;
the complete original published modules and their copyright/license notices
remain unchanged under `../plugins/`, this directory and `../tarballs/`.

The generator `scripts/research/web-branding.mjs` and reviewed transformations
in `web-branding-lib.mjs` reproduce these files from the pinned original inputs.
The offline vendor verifier independently compares all originals against npm
tar members and recomputes each derivative. Module revisions identify the actual
served bytes. No chat content or configured model-provider identity is renamed.

The Connection derivative ignores browser interface online/offline hints for actual loopback authorities. Real RPC readiness and transport loss continue to drive healthy, disconnected and reconnecting states; remote authorities retain the upstream network behavior. The original Connection module remains frozen.

The General settings derivative measures transient reconnection visibility with a monotonic clock; wall-clock adjustments cannot prolong a healthy connection indicator.

The root Harness HTML additionally loads the first-party `/coding-workflow.js` record panel. It calls the existing authorized Remote carrier and native changes endpoints; the original frontend modules and their notices are unchanged. The new panel is Harness-authored and has no upstream product branding.

Responsive host CSS temporarily uncovers pending approvals by hiding the mounted terminal right sidebar on screens up to 600px. No published plugin bytes are changed.
