# Harness Agent presentation adaptations

The product uses its own H mark, wordmark, PWA name and onboarding illustration.
Six browser entry modules have explicitly marked local presentation derivatives;
the complete original published modules and their copyright/license notices
remain unchanged under `../plugins/`, this directory and `../tarballs/`.

The generator `scripts/research/web-branding.mjs` and reviewed transformations
in `web-branding-lib.mjs` reproduce these files from the pinned original inputs.
The offline vendor verifier independently compares all originals against npm
tar members and recomputes each derivative. Module revisions identify the actual
served bytes. No chat content or configured model-provider identity is renamed.
